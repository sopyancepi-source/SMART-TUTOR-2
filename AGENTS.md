# Custom Instructions for AI Assistant

## Operating Modes
- **Mode Eksekusi**: Triggered when the user includes the word **"eksekusi"** in their prompt. In this mode, perform actual code development, edits, and file modifications.
- **Mode Diskusi**: Active when the word **"eksekusi"** is **NOT** present in the prompt. In this mode, respond in discussion mode (explanations, answers, planning, suggestions) without editing code or files.
